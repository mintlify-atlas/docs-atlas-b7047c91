title: "generate_api_request() — Build an Ollama Request Payload"

description: "generate_api_request() constructs and returns the JSON payload for an Ollama generate call, with model validation and option allowlisting."
---

`generate_api_request()` builds the complete request payload that would be sent to an Ollama server's `/api/generate` endpoint, without actually making a network request. It is useful for inspecting exactly what will be sent before dispatching a request, testing integrations against the Ollama API format, logging request details, or constructing custom HTTP pipelines outside of `chat()` and `stream_chat()`. Only recognized option keys are included in the output — unknown kwargs are silently dropped.

## Signature

```python
client.generate_api_request(model: str, prompt: str, **kwargs) -> Dict
```

## Parameters

<ParamField path="model" type="string" required>
  The full model name in `name:tag` format (e.g. `"llama3.2:3b"`). The model must exist in the catalog — a `ValueError` is raised otherwise.
</ParamField>

<ParamField path="prompt" type="string" required>
  The input text to include in the payload.
</ParamField>

<ParamField path="temperature" type="float" default="0.7">
  Controls output randomness. Included in `options` if provided.
</ParamField>

<ParamField path="top_p" type="float" default="0.9">
  Nucleus sampling threshold. Included in `options` if provided.
</ParamField>

<ParamField path="stop" type="list" default="[]">
  List of stop sequences. Included in `options` if provided.
</ParamField>

<ParamField path="num_predict" type="int" default="128">
  Maximum tokens to generate. Included in `options` if provided.
</ParamField>

<ParamField path="repeat_penalty" type="float">
  Token repetition penalty. Included in `options` only if explicitly passed.
</ParamField>

<ParamField path="seed" type="int">
  Random seed for reproducibility. Included in `options` only if explicitly passed.
</ParamField>

<ParamField path="tfs_z" type="float">
  Tail-free sampling parameter. Included in `options` only if explicitly passed.
</ParamField>

<ParamField path="mirostat" type="int">
  Mirostat sampling mode (`0`, `1`, or `2`). Included in `options` only if explicitly passed.
</ParamField>

## Returns

<ResponseField name="payload" type="Dict">
  A dictionary ready to be serialized as a JSON request body, with the following top-level keys:

  ```json
  {
    "model": "llama3.2:3b",
    "prompt": "Explain machine learning",
    "options": {
      "temperature": 0.7,
      "top_p": 0.9,
      "stop": [],
      "num_predict": 128
    }
  }
  ```
</ResponseField>

## Raises

- **`ValueError`** — Raised if the specified model is not found in the catalog.

## Example

```python
payload = client.generate_api_request(
    model="llama3.2:3b",
    prompt="What is gradient descent?",
    temperature=0.8,
    num_predict=512
)
print(payload)
```

<Note>
  Any kwargs that are not in the supported options allowlist (`temperature`, `top_p`, `stop`, `num_predict`, `repeat_penalty`, `seed`, `tfs_z`, `mirostat`) are silently ignored and will not appear in the returned payload. This ensures the output is always a valid Ollama request body.
</Note>
