The `OllamaFreeAPI` class is the single entry point for all interactions with community-hosted Ollama servers. It provides methods for sending prompts, streaming responses, discovering available models and families, inspecting server metadata, building raw request payloads, and obtaining integration parameters for frameworks like LangChain and LlamaIndex.

## Import and Initialization

```python
from ollamafreeapi import OllamaFreeAPI

client = OllamaFreeAPI()
```

<Note>
  Initialization loads the model catalog from bundled JSON files included in the package. No network call is made at startup — the client is ready to use immediately after construction.
</Note>

## Server Selection

`chat()` and `stream_chat()` automatically select the best available server for the given model using a performance-weighted algorithm:

1. All servers hosting the requested model are retrieved from the bundled catalog.
2. Servers are sorted in descending order by `tokens_per_second` from their `performance` metadata — the fastest server is tried first.
3. If a request to the top-ranked server fails (network error, timeout, or unexpected response), the client automatically falls back to the next server in the sorted list.
4. If every server is exhausted without a successful response, a `RuntimeError` is raised.

This means callers never need to manage server selection manually — the client handles retries and failover transparently on every call.
