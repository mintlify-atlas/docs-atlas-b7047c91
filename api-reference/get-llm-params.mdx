`get_llm_params()` performs server selection and returns a dictionary containing the two values needed to instantiate an `OllamaLLM` object in LangChain or LlamaIndex: the `model` name and the `base_url` of the best available server. This removes the need to hardcode a server URL in your integration code — the client picks the highest-performing server at call time, so your integration automatically benefits from the current server landscape.

## Signature

```python
client.get_llm_params(model: Optional[str] = None) -> Dict[str, Any]
```

## Parameters

<ParamField path="model" type="string">
  The full model name in `name:tag` format (e.g. `"llama3.2:3b"`, `"mistral:latest"`). If `None`, a random model from the catalog is selected. Specifying a model explicitly is recommended for reproducible integration behavior.
</ParamField>

## Returns

<ResponseField name="model" type="string">
  The model name that was selected or specified.
</ResponseField>

<ResponseField name="base_url" type="string">
  The base URL of the best available server for the selected model (e.g. `"http://172.236.213.60:11434"`), chosen by the performance-weighted selection algorithm.

  ```json
  {"model": "llama3.2:3b", "base_url": "http://172.236.213.60:11434"}
  ```
</ResponseField>

## Raises

- **`RuntimeError`** — Raised if there are no models or no servers available in the catalog.
- **`ValueError`** — Raised if the specified model name is not found in the catalog.

## Example

```python
from ollamafreeapi import OllamaFreeAPI
from langchain_community.llms import Ollama

api = OllamaFreeAPI()
params = api.get_llm_params(model="llama3.2:3b")
llm = Ollama(model=params["model"], base_url=params["base_url"])
result = llm.invoke("What is machine learning?")
print(result)
```

<Note>
  Each call to `get_llm_params()` performs a fresh server selection. If server performance scores change between calls (for example, after a catalog update), successive calls may return different `base_url` values for the same model. Store the result if you need a stable URL for the lifetime of your `OllamaLLM` instance.
</Note>
