## Why OllamaFreeAPI?

OllamaFreeAPI removes every barrier between you and powerful open-source AI. The library automatically discovers the fastest available server for each model, retries on failure, and streams tokens to your terminal—all with a single Python import.

<CardGroup cols={3}>
  <Card title="No API Keys" icon="key">
    Zero authentication required. Requests work out of the box with no sign-up or billing setup.
  </Card>
  <Card title="Auto Load Balancing" icon="shuffle">
    Servers are ranked by measured token throughput. The fastest node is always selected first.
  </Card>
  <Card title="16+ Active Models" icon="brain">
    LLaMA 3.2, Mistral, DeepSeek-R1, Qwen, Gemma, and more—all verified and tested.
  </Card>
</CardGroup>

## Quick example

```python quickstart.py
from ollamafreeapi import OllamaFreeAPI

client = OllamaFreeAPI()

# Stream a response token by token
for chunk in client.stream_chat("What is quantum computing?", model="llama3.2:3b"):
    print(chunk, end="", flush=True)
```
