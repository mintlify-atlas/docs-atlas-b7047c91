title: "Get Started with OllamaFreeAPI in 2 Minutes"

---

This guide walks you through everything you need to go from zero to a working LLM response: install the package, discover available models, send a blocking chat request, and stream output token-by-token in real time. No accounts, no API keys, and no local Ollama server required.

<Steps>
  <Step title="Install the package">
    Install OllamaFreeAPI from PyPI with a single command:

    ```bash
    pip install ollamafreeapi
    ```

    To make sure you are always running the latest catalog of verified servers and models, upgrade regularly:

    ```bash
    pip install ollamafreeapi --upgrade
    ```
  </Step>

  <Step title="List available models">
    Before sending a request, you can inspect which models and families are available in the bundled catalog:

    ```python
    from ollamafreeapi import OllamaFreeAPI

    client = OllamaFreeAPI()

    # List every available model across all families
    models = client.list_models()
    print(models)
    # ['llama3.2:3b', 'llama3.2:latest', 'llama3:latest', 'gpt-oss:20b', ...]

    # List model families
    families = client.list_families()
    print(families)
    # ['llama', 'gemma', 'qwen', 'mistral', 'deepseek']

    # List models belonging to a specific family
    llama_models = client.list_models(family="llama")
    print(llama_models)
    # ['llama3.2:3b', 'llama3.2:latest', 'llama3:latest']
    ```
  </Step>

  <Step title="Send your first chat">
    `chat()` sends a prompt to the best available server and returns the complete response as a plain string:

    ```python
    from ollamafreeapi import OllamaFreeAPI

    client = OllamaFreeAPI()

    response = client.chat(
        prompt="Explain neural networks like I'm five",
        model="llama3.2:3b",
    )

    print(response)
    # "Imagine your brain is made of tiny light bulbs..."
    ```

    You can pass optional generation parameters such as `temperature` to tune the output:

    ```python
    response = client.chat(
        prompt="Write a haiku about open-source software",
        model="llama3.2:3b",
        temperature=0.9,
    )
    print(response)
    ```
  </Step>

  <Step title="Stream a response">
    `stream_chat()` is a generator that yields text chunks as they arrive from the server, giving you real-time output without waiting for the full response:

    ```python
    from ollamafreeapi import OllamaFreeAPI

    client = OllamaFreeAPI()

    for chunk in client.stream_chat(
        prompt="What is quantum computing?",
        model="llama3.2:3b",
    ):
        print(chunk, end="", flush=True)

    print()  # newline after streaming completes
    ```

    Each `chunk` is a plain string fragment. The `flush=True` argument ensures the text appears in your terminal incrementally rather than all at once at the end.
  </Step>
</Steps>

<Note>
  No API key or sign-up is required. Every request is routed to a community-hosted Ollama server automatically. Server selection is performance-weighted, so you always reach the fastest available node. If that node is unavailable, the library retries the next best option transparently.
</Note>

<Tip>
  Start with `llama3.2:3b` — it is the most reliably available model in the catalog, strikes an excellent balance between speed and quality, and works well for a wide range of general-purpose tasks.
</Tip>
