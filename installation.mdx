This page covers everything you need to get OllamaFreeAPI installed and verified on your machine: the Python version requirement, the single runtime dependency, standard and upgrade install commands, the recommended virtual environment workflow, and a quick import check to confirm the install succeeded.

## Requirements

OllamaFreeAPI requires **Python 3.7 or later**. No other system-level dependencies are needed — in particular, you do not need to install Ollama locally.

| Requirement | Minimum version |
|---|---|
| Python | 3.7+ |
| `ollama` (Python client) | 0.1.0+ |

The `ollama` package is OllamaFreeAPI's only runtime dependency. It provides the underlying `Client` class that handles HTTP communication with Ollama servers. OllamaFreeAPI wraps it with automatic free-server discovery, performance-weighted load balancing, and failover logic — so you get the full power of the official Ollama Python client without needing to manage any server URLs yourself.

<Note>
  You do not need to install or run an Ollama server on your machine. OllamaFreeAPI connects to community-hosted servers automatically. The `ollama` dependency is the official Python client library, not the Ollama application itself.
</Note>

## Install

Install the latest stable release from PyPI:

```bash
pip install ollamafreeapi
```

This installs OllamaFreeAPI and pulls in `ollama>=0.1.0` automatically.

## Upgrade

To update to the latest version — which may include a refreshed server catalog, new model families, or bug fixes — run:

```bash
pip install ollamafreeapi --upgrade
```

## Virtual Environment (Recommended)

Using a virtual environment keeps your project's dependencies isolated from the system Python and other projects. This is the recommended setup for any serious work.

<Steps>
  <Step title="Create a virtual environment">
    Run the following command from your project directory:

    ```bash
    python -m venv .venv
    ```

    This creates a `.venv` folder containing an isolated Python installation.
  </Step>

  <Step title="Activate the virtual environment">
    Activate the environment before installing or running anything:

    <CodeGroup>
      ```bash macOS / Linux
      source .venv/bin/activate
      ```

      ```bash Windows (Command Prompt)
      .venv\Scripts\activate.bat
      ```

      ```bash Windows (PowerShell)
      .venv\Scripts\Activate.ps1
      ```
    </CodeGroup>

    Your shell prompt will change to show `(.venv)` when the environment is active.
  </Step>

  <Step title="Install OllamaFreeAPI">
    With the environment active, install the package:

    ```bash
    pip install ollamafreeapi
    ```

    All dependencies are installed into `.venv` and will not affect your global Python environment.
  </Step>
</Steps>

## Verify Installation

Confirm that OllamaFreeAPI is installed correctly and check the version:

```python
import ollamafreeapi

print(ollamafreeapi.__version__)
# 0.1.4
```

You can also do a quick smoke test to verify the bundled server catalog loads without errors:

```python
from ollamafreeapi import OllamaFreeAPI

client = OllamaFreeAPI()
print(client.list_families())
# ['gemma', 'llama', 'qwen', ...]
```

If both snippets run without exceptions, your installation is working correctly.

## Dependencies

OllamaFreeAPI has a single runtime dependency:

| Package | Version | Purpose |
|---|---|---|
| `ollama` | `>=0.1.0` | Official Ollama Python client — provides the `Client` class used for all HTTP requests to Ollama servers |

`ollama` is the official Python client maintained by the Ollama project. OllamaFreeAPI extends it with three capabilities that the base client does not provide: a bundled catalog of free community-hosted server endpoints, performance-weighted server selection (servers ranked by measured tokens-per-second), and transparent automatic failover when a server is unreachable. You get the full Ollama API surface area plus free infrastructure — without writing a single line of server-management code.
